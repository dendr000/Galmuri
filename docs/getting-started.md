# 프로젝트 시작 가이드

본 프로젝트(Galmuri)를 로컬 환경에서 실행하기 위한 초기 설정 및 구동 방법입니다.

## 용어 설명

- **클론(clone)**: 깃허브에 있는 저장소를 내 PC 로 통째로 내려받는 것.
- **브랜치(branch)**: 같은 저장소 안에서 갈라 둔 작업 줄기. 이 프로젝트는 아래 두 줄기를 씁니다.
- **의존성 패키지**: 이 프로젝트가 동작하려고 가져다 쓰는 외부 라이브러리 묶음 (`package.json` 에 적혀 있음).

## 브랜치 구성

| 브랜치 | 용도 | 설명 |
|---|---|---|
| `main` | 작업용 | 개발이 진행되는 기본 줄기. 로컬 폴더를 직접 읽고 쓰는 기능(전역 검색, 파일 비교 뷰 등)을 모두 포함합니다. |
| `deploy` | 배포용 | 클라우드(Vercel) 배포를 위한 줄기. 서버 파일 시스템에 의존하는 기능을 빼고 콘솔 로그를 제거했습니다. |

- 새 기능과 수정은 `main` 에서 먼저 하고, 배포할 때 `deploy` 로 가져옵니다.
- 작업 브랜치(`chore/…`, `fix/…`)에서 만든 변경은 `main` 과 `deploy` 에 각각 반영해야 하는지 확인합니다.

## 1. 사전 요구 사항 (Prerequisites)
프로젝트를 실행하기 전에 아래 환경이 구축되어 있어야 합니다.
- **Node.js**: v24.16.0 이상

## 2. 프로젝트 가져오기
작업 상황에 맞게 프로젝트 코드를 로컬 환경으로 가져옵니다.

### 최초 1회 실행 시 (Clone)
새로운 PC에서 프로젝트를 처음 내려받을 때 사용합니다. 폴더 이름은 `Galmuri` 로 받습니다.
```bash
git clone <GitHub 저장소 주소> Galmuri
cd Galmuri
```

### 이미 존재하는 경우
기존에 클론한 폴더에서 최신 코드로 동기화할 때 사용합니다.
```bash
git pull origin main
```

## 3. 라이브러리 패키지 설치
프로젝트 구동에 필요한 의존성 패키지를 설치합니다.
```bash
npm install
```

## 4. 로컬 개발 서버 구동
화면(프론트엔드)과 백엔드 서버를 함께 실행합니다.
또는 [GalmuriStart.bat](../GalmuriStart.bat) 파일(또는 그 바로가기)을 실행합니다.
```bash
npm run dev:all
```

화면만 실행하려면 아래 명령을 씁니다.
```bash
npm run dev
```

## 5. 테스트와 점검
```bash
npm test
npm run lint
```

취약점이 있는 패키지를 안전한 버전으로 자동 업데이트(패치)합니다.
```bash
npm audit fix
```
